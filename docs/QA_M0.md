# QA Checklist — M0 (5 minutes gameplay)

## Path 1 — Prudente (baseline)
- Arena 1: scegli **CASH_OUT**
- Se win: cash out (no double)
- Arena 2: **CASH_OUT**
- End run volontaria (se prevista) o muori naturalmente

**Expected**
- 0–1 scar
- ending: **THE_SURVIVOR** o **THE_MARKED**
- UI sempre risk-first

## Path 2 — Risk (core fantasy)
- Arena 1: **FLAWLESS_BLOOD**
- Se win senza danni: applica reward (placeholder) e vai avanti
- Post win: double down una volta
- Arena 2: **FLAWLESS_BLOOD** o scelta libera
- Se fallisci flawless: applica **OPEN_WOUND** e continua

**Expected**
- almeno 1 scar applicata e visibile
- ending: **THE_MARKED** (se 1 scar) o **THE_BROKEN** (2+)

## Path 3 — Suicida (anima di Gallicus)
- Arena 1: **DOUBLE_OR_DIE**
- Risoluzione arena
- Se loss: run termina immediatamente

**Expected**
- ending: **THE_FOOL**
- epilogo coerente
- nessun “fallback” silenzioso
