# MV asset manifest

## Provenance rule

The image directions were generated with the built-in OpenAI image generator
from project-authored prompts and without third-party image inputs. The
selected preview, RGBA overlays and audio prototypes are deterministic local
derivatives generated by the checked-in Python sources. All files remain
review-only until explicit visual/audio approval and runtime integration.

## Generators

- `source/generate_mv_visual_layers.py` creates the selected 1920x1080 base,
  four overlays and the composite.
- `source/generate_mv_audio.py` creates every WAV prototype deterministically.

No review file is referenced by `project.godot`, a `.tscn`, `.tres` or GDScript
consumer. The folder-level `.gdignore` keeps the review package outside the
Godot resource import surface.
