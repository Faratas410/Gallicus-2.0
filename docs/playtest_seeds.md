# Playtest Seeds — Guided Runs (M2)

> Obiettivo: completare una run in 15–25 minuti seguendo un percorso guidato, così da produrre feedback comparabile.

## Istruzioni rapide

1. Inserisci il seed nella schermata scommessa (campo **Seed (opzionale)**) prima di scegliere la prima bet.
2. Segui il percorso consigliato per 3–6 step.
3. A fine run allega il **run_summary_<seed>.json** esportato in `user://`.
